# OrdenaFotos Socio

App Android local para analizar la galería, proponer categorías y mover únicamente las fotos aprobadas a `Pictures/OrdenaFotos/`.

- No sube fotos a servidores.
- ML Kit Image Labeling y OCR latino van integrados en la APK.
- No borra fotos.
- Solicita confirmación de Android antes de modificar archivos ajenos a la app.
- Puede separar además por año/mes.
